# Разработка виджетов

Внутренний контракт WebSynth описан в [модели патча](src/entities/project/model/patch.ts). Каждый экземпляр имеет стабильный ID, тип, положение и сериализуемые параметры. Схема портов возвращает их ID, направление и тип сигнала. Движок сопоставляет соединения по ID узлов и портов.

1. Зарегистрируйте тип в `kinds` и `modules`. Задайте входы и выходы `audio` или `midi` и параметры по умолчанию. Для динамических портов сохраняйте существующую нумерацию.
2. В [аудиодвижке](src/pages/rack/lib/audio-engine.ts) создайте внутренние AudioNode или AudioWorkletNode при создании runtime. Применяйте изменения через `apply`. Подключите внутренние узлы к шине или терминалам runtime. Маршрутизацию между виджетами выполняет `AudioEngine.sync`.
3. При удалении runtime остановите источники, снимите обработчики и освободите аудиоресурсы. При изменении параметра сохраняйте runtime, чтобы соседние ветви продолжали работать.
4. Добавьте тип в [каталог страницы](src/pages/rack/ui/rack-page.tsx), подпись и контролы в [представление модуля](src/pages/rack/ui/module-controls.tsx). Опишите диапазоны параметров в модели патча и проверьте обработку типа при [импорте JSON](src/entities/project/model/project-json.ts). Состояние движка и DOM-объекты не входят в JSON.
5. Для несовместимого изменения структуры JSON увеличьте `schemaVersion` и добавьте миграцию рабочего патча и всех его именованных версий.
