# Modular Audio Rack

Браузерный аудиорэк на TypeScript, React Flow, Web Audio и Web MIDI. Для работы используйте настольный Chrome.

```sh
npm ci
npm run dev
```

Откройте локальный адрес из терминала. Добавьте Oscillator и Output, соедините правый порт Oscillator с левым портом Output и нажмите «Включить звук». Двойной клик по узлу открывает параметры.

Для MIDI добавьте MIDI Input и MIDI Synth. В параметрах MIDI Input разрешите доступ и выберите устройство и канал. Соедините MIDI Input → MIDI Synth → Output. Если вход Output занят, появится Mixer. Второе аудиосоединение из занятого выхода создаёт Splitter.

Рабочее состояние и именованные версии сохраняются в IndexedDB. Меню проекта позволяет импортировать и экспортировать JSON с историей версий. Приложение можно собрать командой `npm run build`. Для тестов графа и формата проекта используйте `npm test` на Node.js 22.13 или новее.

Выбор аудиовыхода зависит от доступных Chrome устройств. Виртуальное устройство, предоставленное ОС, можно выбрать тем же способом, что и физическое. При недоступности выбранного выхода используется системный.
